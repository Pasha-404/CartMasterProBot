# CartMasterProBot

Telegram-бот для списка покупок. Бот работает через Telegram webhook и развёрнут на VPS.

## Возможности

- Добавляет товары, отправленные через запятую или с новой строки.
- Показывает товары, которые нужно купить, кнопками под сообщением.
- По нажатию на кнопку переносит товар в раздел «Купленные» и обновляет активное сообщение списка.
- Удаляет обработанное сообщение с товаром только после того, как оно отобразилось в списке, поэтому список остаётся последним сообщением в чате.
- После покупки последнего товара сохраняет завершённый список в чате и создаёт отдельный новый пустой список.
- Кнопка «Новый список» завершает текущее сообщение и создаёт следующее отдельное сообщение со списком.
- Добавляет Unicode-значки к распространённым товарам, не меняя введённые названия.
- Принимает длинные названия товаров и компактно сокращает их только в кнопках и истории списка.
- Поддерживает команды `/start` и `/clear` для создания нового списка.
- Не обрабатывает один и тот же Telegram update повторно.

## Правила работы

- Один список привязан к одному Telegram-чату. В групповом чате он общий для всех участников.
- Чтобы бот удалял обработанные сообщения с товарами в группе, дайте ему право администратора «Удаление сообщений».
- Списки хранятся только в памяти приложения и очищаются после его перезапуска, в том числе после деплоя.
- В одном списке может быть не более 20 товаров. Полное название сохраняется; в интерфейсе длинное название сокращается.
- Если бот не уверен, какой значок соответствует товару, название выводится без значка.

## Технологии

- Java 17
- Spring Boot
- Maven
- Telegram Bot API DTO и HTTPS-клиент JDK с проверкой имени хоста
- systemd и Nginx на VPS

## Локальный запуск

Нужны Java 17 и Maven. Перед запуском задать переменные окружения процесса:

```powershell
$env:BOT_TOKEN = "<токен бота>"
$env:WEBHOOK_SECRET = "<секрет webhook>"
$env:SERVER_PORT = "8081"
mvn spring-boot:run
```

По умолчанию приложение слушает `127.0.0.1:8081`, а webhook-путь — `/webhook`.
Чтобы бот принимал реальные обновления Telegram локально, этот адрес должен быть доступен Telegram по HTTPS через обратный прокси или туннель.

Не добавляйте значения `BOT_TOKEN` и `WEBHOOK_SECRET` в репозиторий, логи или документацию.

## Сборка и тесты

```bash
mvn clean package
```

Maven запускает тесты и создаёт JAR:

```text
target/CartMasterProBot-1.0.0.jar
```

## Деплой

Каждый push в ветку `master` запускает GitHub Actions: сначала проверяется сборка, затем VPS получает именно этот commit, собирает JAR, перезапускает сервис и ждёт ответ `/health`.

Конкретная схема, переменные GitHub Actions, требования к VPS, диагностика и откат описаны в [DEPLOY_VPS.md](DEPLOY_VPS.md).

## Структура проекта

```text
src/main/java/org/cartmaster/
  bot/           обработка Telegram update
  controller/    HTTP endpoint webhook
  config/        конфигурация из переменных окружения
  service/       списки покупок и защита от повторных update
src/test/java/   модульные тесты
```
